⚙️ System Engineering & DSA Rationale

CampusFind combines a robust relational backend with a custom in-memory Binary Search Tree (BST). While MySQL provides ACID persistence and B-Tree disk indexes, our in-memory BST implements $O(\log n)$ ordered ID and chronological lookups, accompanied by an interactive educational visualizer demonstrating node insertion, search path traces, and three-case deletions.
